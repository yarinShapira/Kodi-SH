הדרך הכי אמינה (Downloader)

להורדה מיידית ב-Downloader, הזן את כתובת ה-APK הישירה ל-32-ביט. הקוד הכללי 5827414 טוב לדף בחירה, אבל אם Downloader נתקע על דף HTML — השתמש בכתובת הישירה.

1. Settings → My Fire TV → Developer options → Apps from Unknown Sources → On (ואפשר ל-Downloader).

2. פתח את Downloader הכתום ובשדה ה-URL הזן: yarinshapira.github.io/Kodi-SH/downloads/Kodi-SH-32bit.apk

3. לחץ GO — ההורדה תתחיל מיד (~75MB).

4. בסיום → Install → Done → מחק את הקובץ.

5. עם סיום ההתקנה, פתח את האפליקציה — ה-wizard וה-FENtastic כבר מותקנים.

רוצה מספר אחד לכל המכשירים? הזן 5827414 כדי לפתוח את דף הבחירה הכללי: https://yarinshapira.github.io/Kodi-SH/downloads/. אם Downloader נשאר על "Connecting", חזור והזן את כתובת ה-APK הישירה למעלה.
